{%- comment -%} Math rendering. Included only when a page sets `math: true` in front matter. How it works: kramdown (Jekyll's Markdown engine) turns $$...$$ into \( ... \) for inline math and \[ ... \] for display math. KaTeX's auto-render extension then finds those delimiters and renders them — see assets/js/math.js for the configuration. Note we only register the backslash delimiters, never a bare `$`. That way a dollar sign in ordinary prose or in a code block is never mistaken for math. {%- endcomment -%}
